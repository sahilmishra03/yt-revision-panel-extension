# YouTube Revision Panel 💡

Mark important moments in **YouTube playlist videos** and revise them later using a clean, movable Revision Panel — directly inside YouTube.

---

## 🚀 What is this?

While studying from long YouTube playlists, it’s hard to remember:
- which video had an important explanation
- at what exact time to revise it later

**YouTube Revision Panel** solves this by letting you mark videos with timestamps and revise them anytime.

---

## ✨ Features

- 💡 Mark playlist videos at the current timestamp  
- ⏱ Automatically saves the exact time  
- 📋 Playlist-specific Revision Panel  
- ▶ One-click resume from saved time  
- ❌ Unmark videos when revision is done  
- 🧲 Draggable & minimizable panel  
- 🌙 Clean dark UI  
- 🔁 Works after reload & browser restart  

---

## 📍 Where it appears

- **Mark Button** → Only on playlist video watch pages  
- **Revision Panel** → Playlist page **and** playlist video page  

---

## 🖥 How it works

1. Open a video that is part of a playlist  
2. Click the **💡 Mark** button while watching  
3. Video title and timestamp are saved  
4. Open the playlist page or any playlist video  
5. Use the **Revision Panel** to revisit marked videos

## 🛠 Installation (Local)

1. Download or clone this repository  
2. Open Chrome and go to:
   ```
   chrome://extensions
   ```
3. Enable **Developer mode**  
4. Click **Load unpacked**  
5. Select the project folder  

The extension is now ready to use.
